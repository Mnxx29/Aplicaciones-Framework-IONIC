# Aplicaciones Framework IONIC

Repositorio principal para el desarrollo de proyectos y actividades prácticas de la asignatura de **Aplicaciones Móviles** (Cuarto Semestre de Ingeniería).

---

## 📁 Estructura del Repositorio

- **`app/`**: Aplicación Ionic basada en plantilla de pestañas (*Tabs*) con interfaz personalizada (catálogo/tarjetas interactivas y navegación).
- **`mi-primera-app/`**: Primera aplicación móvil de prueba y exploración de componentes básicos de Ionic.
- **`Introduccion_Ionic_Primera_App.pptx`**: Material y apuntes de clase introductorios.

---

## 🚀 Requisitos y Configuración

Para ejecutar cualquiera de las aplicaciones en este repositorio:

1. Asegúrate de tener instalado **Node.js** y el **CLI de Ionic**:
   ```bash
   npm install -g @ionic/cli
   ```

2. Entra en la carpeta de la aplicación correspondiente e instala sus dependencias:
   ```bash
   cd app
   npm install
   ```

3. Inicia el servidor de desarrollo local:
   ```bash
   ionic serve
   ```
